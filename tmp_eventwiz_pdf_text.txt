EventWiz Mapping Tool – Product Overview 
Commercial Positioning 
The EventWiz mapping tool is a planning and operational layout system designed specifically for event organisers. 
It allows teams to build accurate site layouts using live maps, infrastructure assets and zone planning tools within 
the EventWiz platform. 
Event planning often relies on static PDFs, spreadsheets and disconnected drawings. The EventWiz mapping tool 
replaces those methods with a single workspace where site design, infrastructure placement and operational 
planning are managed together. 
This provides organisers with a clear view of the event site and improves coordination between production teams, 
suppliers and safety managers. 
 
1. The Problem in Event Planning 
Many events still manage site layouts using a mix of tools. 
Typical methods include: 
• PowerPoint site plans 
• Illustrator drawings 
• PDF maps 
• Excel infrastructure lists 
• email instructions to suppliers 
These systems create several problems. 
Issue Impact 
Version confusion teams working from different layouts 
Poor communication suppliers misunderstand site plans 
Limited measurement areas and distances estimated 
Slow updates layout changes require full redraw 
Operational risk safety zones not clearly defined 
For medium and large events this becomes a major operational risk. 
 
2. The EventWiz Solution 
The EventWiz mapping tool brings site planning directly into the event management platform. 
Organisers can: 
• design layouts on a real map 
• define zones and operational areas

Proposition  
The EventWiz Mapping & Drawing Tool will allow organisers to build, manage and share scaled event site layouts 
using a live map base layer. It will combine location search, visual planning and operational overlay tools in one 
workspace so event teams can design sites, mark infrastructure, define zones and calculate usable space. 
Core base layers 
• Google Maps base layer 
• Satellite and standard map views 
• Optional site image or CAD/PDF overlay for custom venue plans 
• What3Words search and point reference 
Google Maps already supports custom overlays and data layers, so EventWiz can place its own assets, GeoJSON 
features and custom site plan layers over the map.  
Drawing and zoning tools 
• Draw polygons, lines, rectangles and circles 
• Create named zones such as arena, public area, backstage, trader village, emergency route, parking, camping 
or sterile area 
• Resize, reshape and move objects 
• Set line thickness, line colour, fill colour and opacity 
• Add labels and notes to every object 
• Duplicate zones and assets for repeat use 
• Snap-to-grid or guided alignment for cleaner plans 
Google’s drawing tools support user-drawn shapes and the platform also supports GeoJSON and styled data layers, 
which is a sensible structure for storing EventWiz layouts.  
Asset library 
This is where the feature becomes useful for event delivery rather than just drawing. 
Create a reusable asset library of icons and objects such as: 
• fencing panels

The EventWiz mapping tool requires a clear technical structure so the platform can manage map rendering, drawing 
objects, infrastructure assets and spatial calculations. The architecture must support browser use, future mobile use 
and large event layouts with hundreds of objects. 
This section defines the technical structure developers should follow when building the EventWiz mapping 
environment.

The EventWiz mapping tool will operate using a layered web architecture. 
Layer Purpose 
Front-End Map Interface User interaction and drawing tools 
Map Engine Map rendering and coordinate system 
Geometry Engine Measurements and spatial calculations 
Data Storage Saving layouts, zones and assets 
Asset Library Service Infrastructure object catalogue 
API Layer Communication between platform modules 
Export Engine Generating PDFs and images 
This structure allows EventWiz to scale without rebuilding the mapping component later.

The EventWiz mapping tool requires a structured database so layouts, zones, assets and spatial data can be stored, 
edited and reused across events. The schema must support multiple events, multiple layouts per event, and 
hundreds of objects per layout without performance issues.

potential GIS integration.

Database Schema – Mapping & Drawing Tool 
The EventWiz mapping tool requires a structured database so layouts, zones, assets and spatial data can be stored, 
edited and reused across events. The schema must support multiple events, multiple layouts per event, and 
hundreds of objects per layout without performance issues. 
All spatial objects will be stored using GeoJSON geometry to maintain compatibility with mapping libraries and 
potential GIS integration. 
 
1. Core Database Structure 
The mapping system will use the following primary tables. 
Table Purpose 
events master event records 
event_layouts site layouts linked to an event 
layout_objects zones, shapes and drawn elements 
layout_assets placed infrastructure assets 
asset_library reusable asset definitions 
layout_layers layer management 
layout_annotations notes and labels
